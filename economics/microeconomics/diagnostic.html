C6短期总成本 TC = 100 + 20Q − 2Q² + 0.2Q³，求 MC、AVC、ATC，并求 AVC 最低时的产量与该点 AVC 值。

C8垄断者面对需求 P = 100 − 2Q，成本 C = 20Q。求利润最大化产量与价格，并算勒纳指数。为什么价格高于边际成本？

A1f′(x) = 3x² − 12x + 9 = 3(x−1)(x−3)；f″(x) = 6x − 12 → x=1 为极大，x=3 为极小。

A3x = y = 5，z = 25。一阶条件 y = λ、x = λ，得到 x = y。
A4x = 24，y = 4。Cobb-Douglas 份额法则：x = αM/pₓ，y = βM/pᵧ。
A5f″(x) = −1/x² < 0；二阶导为负表示边际量递减。
A6y = 4，x = 8；两条直线的交点。
A710 元。
A8斜率 −2；x 每增加 1 单位，y 下降 2，即机会成本 / 边际替代率。
B1需求曲线不变（供给曲线右移），且市场价格可自由调整。
B2需求曲线向下倾斜：定价越高，购买人数越少；主办方是在需求曲线上选点，不能随意脱离市场。
B3总效用与边际效用的区别：水的边际效用低（供给多），钻石的边际效用高（供给少）。
B4下降。涨价带来的单位收益被销量下降完全抵消时，|E| > 1。
B5不一定。取决于劳动需求弹性与市场结构；竞争市场、需求缺乏弹性时失业效应小，还可能被买方垄断下的就业增加抵消。
B6不免费。时间、注意力、替代方案的收益都是机会成本。
B7受需求曲线约束：定价过高会失去销量，垄断者的最优解是 MR = MC。
B8信息不对称导致逆向选择：买方无法区分质量，只愿出平均价，好货退出市场。
C1100 − 2P = 3P − 25 → P = 25，Q = 50。
C2CS = ½ × 50 × (50 − 25) = 625；PS = ½ × 50 × (25 − 25/3) ≈ 416.7。
C3(−20/90) ÷ (2/11) ≈ −1.22 → 富有弹性。
C4x = 5，y = 10。
C5替代效应恒为负（价格降、需求增）；收入效应方向取决于商品类型：正常品同向、劣等品反向；吉芬品是收入效应压倒替代效应。
C6MC = 20 − 4Q + 0.6Q²；AVC = 20 − 2Q + 0.2Q²；ATC = 100/Q + 20 − 2Q + 0.2Q²；AVC 最低在 Q = 5，此时 AVC = 15。
C7需要知道 AVC：若 P ≥ AVC 则短期继续生产（亏损小于固定成本），否则停业。
C8MR = 100 − 4Q = MC = 20 → Q = 20，P = 60；勒纳指数 = (60 − 20)/60 ≈ 0.67；因为垄断者面对向下倾斜的需求曲线，多卖一单位必须降价。
